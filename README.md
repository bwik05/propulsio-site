# Propulsio — site public

Page statique publique affichant « page up », hébergée sur GitHub Pages.

Domaine : https://propulsio.ch/ (`www.propulsio.ch` redirige vers ce domaine).
Le domaine et les e-mails restent gérés chez Infomaniak ; seul le site web
est hébergé chez GitHub. Aucun transfert FTP n'est nécessaire.

Seuls les fichiers destinés à être publics doivent être ajoutés à ce dépôt.
La publication est automatique après chaque envoi sur la branche `main`.
